## NMH 协作探索（精简装载版 · 全文 = 协议 §04-NMH）

**触发**（满足任一即走 NMH，不直接执行）：需求含方案/设计/评估/迁移/选型/对比/重构/规划类词 ｜ 含隐含决策点（"优化一下"= 优化什么维度？）｜ human 说"我不确定/你觉得呢"。拿不准 = 触发（漏触发 = 做偏重做；误触发 = 多几轮问答）。

**双模式**：探索（边界未知：自由 Q&A + 画决策树骨架，判断 human 知识深度给恰当解释）→ 锁定（节点 ≥3 无重大未知：逐节点给选项 + 推荐 + 理由，human 点头）。锁定中发现新未知 → 回探索。

**问题格式**（一次一个）：
```
[D{n}] {主题} — 选项: A/B — 推荐: {X}（一句话理由）— 影响: {选错会怎样}
```

**锁定反应表**：确认✅ / 修改✅(修正版) / 否决✅(新选项) / 搁置🏳️ / 你不会🏳️(诚实声明,不编)。全部 ✅🏳️ = NMH 完成。

**锁定前七问**：①每节点有 human 明确确认？②节点间矛盾？③有 🏳️ 其实 human 能拍板的没问？④约束落进树了？⑤域已知瓶颈作为约束写了？⑥术语冲突都统一了？⑦另一 Agent 冷读这份树能不问人开干吗？

**写盘**（文件即契约，10 行也要写）：决策树（节点 + 选项 + human 原话 + 时间戳）/ 约束 / 术语对齐日志 / 学习摘要（下次 NMH 读旧文档不重复教学）。

**演化**：追加不覆盖 `[D{n}-e1]`；影响 >3 节点 → 新建 v2（旧版留审计）。

**禁止**：替 human 锁定 ｜ 编知识填 🏳️ ｜ 锁定前开始产出 ｜ 口头承诺（文件即契约）。

**spec 结构化（锁定必出）**：goal / acceptance[]（{id, check, pass_criteria} 可机器判定优先）/ out_of_scope / decision_class / contract_refs / critical_delivery。
