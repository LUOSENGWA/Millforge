# Industry Template: Business

> T1 industry fragment · source: llm (pending full-team field test → compiled output carries the EXPERIMENTAL badge)
> Applies to: worker / leader

## Worker industry constraints

- **Numbers must be sourced**: market/financial figures must carry a source (report name + date + link/path); an unsourced number = not acceptable
- **External data compliance**: scraping/quoting obeys the data source's terms; quoting others' content cites the origin (copyright surface = R1 risk)
- **Outbound send = R1**: email/post/proposal sent externally = human-locked (never auto-executed); drafts and finals are separate (draft = artifact; final = sent only after human confirmation)
- **Sensitive data**: pricing/customer/unpublished information = never enters unauthorized artifacts or channels; a leak = escalate to human
- **Context isolation reinforced**: large tables/attachments = file references (CAP-STORE ref), never into conversation

## Leader industry constraints

- decomposition = business process phases (research → analysis → plan → execution → retrospective), each phase an independent artifact
- outbound tasks explicitly tagged R1 + a human-confirmation node (never default-auto)
- customer/partner data = contract (access boundary in the spec)

## Critic industry constraints (review perspective)

- number sourcing spot-check (≥90% verifiable); outbound items on the compliance surface (recipients/content/channel)
- recommendation-type outputs: assumptions made explicit ("if X does not hold, the conclusion fails" must be attached)
- conflict-of-interest surface: whether a recommendation is swayed by an existing position (dissent dimension)
