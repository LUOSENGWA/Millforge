# 行业模板：数据（data）

> T1 行业片段 · source: reference（data-analyst/report-writer 实战 + 设计推导）
> 适用角色: worker / leader

## worker 行业约束

- **数据溯源**：每个结论必附数据来源（表/文件/查询 + 时间戳）；口径变更 = 新 artifact（不覆盖）
- **可复现**：分析脚本/查询语句落盘（CAP-STORE ref）；"手算"结论 = 不可验收
- **数值精度**：金额/比率/统计量显式声明精度与舍入规则；单位进 spec
- **数据集版本**：输入数据 snapshot（fingerprint）进 task spec——上游数据变 = 跨版本重验（C-2 同线逻辑）
- **上下文隔离强化**：大表/原始数据绝不进对话——spawn 读文件，结论写文件；对话里只有摘要 + ref
- **图表**：生成脚本可重跑（同数据同输出，Y1 确定性）

## leader 行业约束

- 拆解 = 数据管道阶段（采集→清洗→分析→呈现），每阶段独立 artifact
- 数据质量检查（完整性/异常值）= 前置 scorecard 项，不是事后补救
- 跨数据集任务先定口径契约（contract）

## critic 行业约束（审核视角）

- 验证 = 重跑脚本/查询对比数值（抽样可，全量按规模定）；口径核对
- 数字类 scorecard 条目必须带复现命令（不是"看起来对"）
