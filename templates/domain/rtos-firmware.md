# 域片段：RTOS/固件通用（rtos-firmware）

> T2 域片段 · source: reference | 适用: worker | spawn 域: rtos

## 上下文输入（spawn 从文件读）

- RTOS 类型 + 版本（FreeRTOS/Zephyr/RT-Thread…，spec 字段 = contract）
- 任务清单（优先级/栈大小/周期，ref）
- 目标硬件说明（同 mcu 域）

## 执行约束

- 任务资源声明：每个任务/队列/信号量的栈大小 + 优先级进 spec（不猜默认值）
- 临界区/共享资源：互斥策略显式（锁/队列/无锁），新共享资源 = 声明
- 看门狗/低功耗改动 = R1（系统级行为，人锁）
- 栈溢出检查：构建含栈使用率报告（scorecard 附证据）
- 优先级反转风险：新增锁必查持锁任务优先级链

## 验收要点（critic 视角）

- 资源声明 vs 实际（栈/队列配置逐项核对）
- 优先级链审查（新增锁的持锁路径）
- 确定性：无隐式阻塞（任务内 IO 声明）
- 构建 + 静态分析（如配置了）可复现
