# 域片段：数据可视化（data-visualization）

> T2 域片段 · source: reference | 适用: worker | spawn 域: viz

## 上下文输入（spawn 从文件读）

- 数据 + 字段语义（ref，同 data-analysis 隔离纪律）
- 可视化目标（受众/用途/渠道——决定精度与格式）
- 设计规范（配色/字体/模板，如有 = contract）

## 执行约束

- 图表类型匹配数据语义（时间序列→折线/类别→条形/占比→谨慎用饼图）
- 轴/单位/刻度诚实：不截断误导（断轴必标注）；单位进图
- 复现：图表由脚本生成（数据 ref + 脚本 ref），非手工拼图
- 大屏/小屏双版（渠道要求时）；交互原型 = 说明可交互点（非交互渠道降级为静态 + 注释）
- 数据脱敏：对外图表检查敏感字段（客户名/精确金额，按 spec 脱敏规则）

## 验收要点（critic 视角）

- 数值一致性：图上关键值 vs 数据源抽样核对
- 误导检查：轴起点/断轴/比例/颜色语义
- 复现：脚本重跑输出一致
- 可读性：标题/图例/标注完整（冷读者 3 秒能读主题）
