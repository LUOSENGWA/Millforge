# 域片段：安全（security）

> T2 域片段 · source: reference | 适用: worker, critic | spawn 域: security

## 上下文输入（spawn 从文件读）

- 审计对象清单（代码/配置/依赖，文件引用）
- 威胁模型边界（本任务防什么/不防什么——12-REDLINES 边界声明）
- 现有安全控制清单（baseline）

## 执行约束

- **凭据零残留**：token/密钥绝不进 artifact/对话/日志；发现即升级（I3）
- 扫描 = 可复现命令（工具 + 版本 + 参数进 scorecard）
- 漏洞报告格式：位置 + 复现步骤 + 影响面 + 建议（每条独立 artifact 条目）
- 修复验证：修前/修后同命令对比（证据链完整）
- 安全配置变更 = R1（人锁）

## 验收要点（critic 视角）

- 逐条复现（报告里的复现步骤必须能跑）
- 误报过滤：标"误报"的必须附理由（不是跳过）
- 修复不引入回归（改动面检查）
- 边界诚实：声明"本审计不覆盖 X"（不假装全量安全）
