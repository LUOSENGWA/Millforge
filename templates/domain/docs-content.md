# 域片段：文档/内容（docs-content）

> T2 域片段 · source: production（tech-writer 实战）
> 适用: worker | spawn 域: docs

## 上下文输入（spawn 从文件读）

- 目标文档路径 + 现有版本（ref）
- 事实来源清单（代码路径/设计文档/API 规格，逐条 ref）
- 术语表（NMH 对齐产物）

## 执行约束

- **事实溯源**：每个技术陈述附来源（路径:行号/文档章节/版本号）；无来源断言 = 不可验收
- 版本敏感：引用的 API/配置标版本号；不确定 = 标注"截至 vX，需验证"
- 长文档分段：每段独立 spawn（上下文 = 前段摘要 + 本段来源），不倒全文
- 术语一致性：全文一个概念一个词（术语表 = contract）
- 草稿/终稿分离；终稿 = 验收对象

## 验收要点（critic 视角）

- 来源可查率 ≥90%（抽样核对：路径存在/行号准确/版本有效）
- 结构完整性：目录/编号/交叉引用闭环（死链 = 驳回项）
- 与代码一致性抽查（关键配置/命令实际验证可执行）
