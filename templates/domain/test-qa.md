# 域片段：测试/QA（test-qa）

> T2 域片段 · source: reference | 适用: worker, critic | spawn 域: test-qa

## 上下文输入（spawn 从文件读）

- 被测对象 spec（acceptance criteria，ref）
- 测试基线（现有测试清单 + 上次结果快照）
- 环境说明（测试环境/依赖/数据准备，ref）

## 执行约束

- 测试用例 = spec 的 acceptance 逐条映射（无对应测试的 criterion = 验收缺口，显式标注）
- 结果证据：命令 + 完整输出（文件引用）+ 通过/失败统计
- 失败分类：产品缺陷 / 测试缺陷 / 环境问题——三类分开报告，不混
- 数据隔离：测试数据不污染生产（R1 面检查）
- 回归范围声明：本次验证覆盖/未覆盖的模块清单（诚实边界）

## 验收要点（critic 视角）

- 用例映射完整性（criterion ↔ 测试双向可查）
- 结果重抽：抽样重跑（≥20% 或 5 条，取多）验证证据真实
- 失败项复现（每个"产品缺陷"必须可复现，不可复现 = 降级为"疑似"）
- 环境声明一致性（测试跑的环境 = 声明的环境）
