# Domain Fragment: Research Reports (research-reports)

> T2 domain fragment · source: production (research/report team field work)
> Applies to: worker | spawn domain: research

## Context Input (spawn reads from files)

- research question + scope definition (spec: in/out of scope)
- source material inventory (ref; tiered: primary/secondary/inference)
- report template/structure specification (if any = contract)

## Execution Constraints

- **three-level evidence chain**: every key argument = argument → basis → source, three levels traceable; an unsourced argument = not acceptable
- distinctions: facts (sourced) / analysis (derivation chain explicit) / recommendations (premise assumptions tagged)
- counter-evidence: key conclusions carry "if X does not hold, this fails" (dissent dimension; honesty)
- long reports spawned per section (each section an independent spec + context = previous section's summary + this section's sources); never the full text
- number/date/name reconciliation: key entities need at least dual sources or a primary source (single source tagged)
- draft/final separation; citation format unified (into the contract)

## Acceptance Points (critic perspective)

- argument-basis-source three-level spot-check (all of ≥10 key arguments checked)
- logical consistency: conclusions and evidence point the same way (no over-inference)
- source authenticity: sample visits (≥90% checkable)
- structural integrity: abstract/body/conclusions/citations closed; no dead links in sections
- honesty: uncertainty tagged (no dressing up single sources/speculation)
