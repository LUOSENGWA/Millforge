# 域片段：数据分析（data-analysis）

> T2 域片段 · source: production（data-analyst 实战）
> 适用: worker | spawn 域: data-analyst

## 上下文输入（spawn 从文件读）

- 数据文件 + 字段说明（ref；大表只给 schema + 抽样，不全量进对话）
- 分析目标 + 口径定义（spec：指标公式/分组维度/时间窗）
- 历史分析结论（如有，ref——对比基线）

## 执行约束

- **口径先行**：指标公式/舍入/时区/去重规则进 spec，分析前锁定（口径歧义 = R6 上报，不猜）
- 可复现：分析脚本落盘（CAP-STORE ref）+ 数据 snapshot 指纹；结论必须能重跑
- 数据质量前置检查：缺失率/异常值/重复——先报质量再出结论（质量问题影响结论时显式标注）
- 图表 = 生成脚本可重跑（同数据同输出）；图表脚本与数据同 artifact
- 大文件：只进摘要 + ref；数值结论附计算过程（公式 + 关键中间值）

## 验收要点（critic 视角）

- 复现：重跑脚本数值一致（容差声明）
- 口径核对：结论指标 = spec 定义（不是"差不多"）
- 抽样核对：关键数值独立重算（≥3 个关键数字）
- 结论诚实：数据不支持的推断必须标注"推测"（不粉饰）
