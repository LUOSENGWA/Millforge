# 域片段：ML/数据科学（ml-data）

> T2 域片段 · source: reference | 适用: worker | spawn 域: ml-data

## 上下文输入（spawn 从文件读）

- 数据说明（来源/口径/字段表，文件引用）
- 模型/实验配置（config = contract；随机种子必填）
- 评估基线（已有指标快照）

## 执行约束

- **可复现三件套**：种子 + 依赖版本（pip freeze ref）+ 数据 snapshot 指纹，缺一 = 不可验收
- 实验记录：每个实验 = 独立 artifact（配置 + 指标 + 结论），append 不覆盖
- 指标口径：评估集划分/指标定义进 spec（口径变更 = 新 artifact）
- 大文件（模型/数据）= CAP-STORE ref，严禁进对话
- GPU/长时训练任务 = R2（资源消耗，声明时长 + 预算）

## 验收要点（critic 视角）

- 重跑复现（种子 + 数据指纹一致 → 指标一致，容差声明）
- 数据泄漏检查（训练/评估集边界）
- 基线对比：新指标 vs 快照（无提升 = 结论必须诚实，不粉饰）
